# Deep Learning Breast Cancer Detection

Final Year Project investigating deep learning for binary classification of benign and malignant mammograms using the CBIS-DDSM mass subset.

## Project Code

The complete experimental pipeline is provided in:

`final_fyp_notebook.ipynb`

The notebook includes data preparation, custom CNN experiments, transfer learning with VGG16 and ResNet50, CLAHE preprocessing, model evaluation, robustness analysis, McNemar significance testing, and Grad-CAM interpretability analysis.

## Dataset

This project uses the CBIS-DDSM mammography dataset. The dataset is not included in this repository due to its size.

## Trained Models

Trained model checkpoints are not stored in this GitHub repository due to file-size limitations.

## Deployment

The final ResNet50 + CLAHE model is deployed through the accompanying Streamlit application.
